# wolkcoffee.co.uk

Website for WOLK Coffee & Cakes, 16 Hill Rise, Richmond, London TW10 6UA.
Static site published with GitHub Pages.

The pages are generated by `source/build.py` (all copy, prices and schema live there).
To change the site: edit `source/build.py`, run `python3 source/build.py`, copy the
contents of the generated `dist/` folder to the repository root, commit and push.
